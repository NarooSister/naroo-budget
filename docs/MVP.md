# MVP 완료

완료일: 2026-09-30

**Naroo의 MVP 개발, 통합 검증, 구조 정리를 완료했다.** 이후 작업은 신규 기능 추가와 유지보수다.

## 완료 기능

- Google 로그인, 세션 유지·로그아웃, Household 연결 판정
- 같은 Household의 거래 공유와 수입·지출 생성/수정/삭제
- 월별 내역, 수입·지출 필터, 날짜·구성원·메모 입력
- 현재 서울 월의 수입·지출·잔액과 최근 내역
- 월 전체 지출 예산 설정·수정, 미설정/0원/초과 구분
- 카테고리 추가·이름 수정·삭제 시 미분류 이동과 구성원 조회
- Household 단위 RLS와 모바일 우선 화면

## 검증

- 현재 로컬 코드: Flutter 정적 분석 통과, 전체 테스트 149개 통과. 웹 릴리스 빌드 성공은 기존 MVP 검증 결과다.
- 실제 두 Google 계정의 거래 공유·수정·삭제: 사용자 확인
- 실제 Supabase RLS·공동 거래 CRUD·다른 Household 거래 차단: 사용자 실행 SQL의 PASS 결과 확인
- 예산 계산·저장, 금액·월 경계·오류·재시도: 자동 테스트로 확인

카테고리 삭제/미분류 전환의 DB migration·RLS·동시성 검증은 위 MVP 당시 운영 검증과 별개다. 새 검증 SQL은 README의 DB 절차를 따르며, 운영 적용 결과는 아직 확인하지 않았다.

## 개발 기준

- UI → Riverpod → Repository → Supabase 구조를 유지한다.
- 공통 금액·날짜 규칙과 세션을 분리하고, 데이터 계약·Supabase 구현·Provider 조립을 구분했다.
- CI는 정적 분석과 테스트만 실행한다. 커버리지 측정은 선택 사항이다.

## 운영 확인

GitHub CI와 Cloudflare 배포의 실제 상태는 저장소 연결·배포 시 확인한다. 기존 웹 빌드의 CupertinoIcons 폰트 경고가 남아 있다.
