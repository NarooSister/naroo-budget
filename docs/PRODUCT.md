# 제품

Naroo는 부부가 같은 Household의 수입·지출을 빠르게 기록하는 가계부다. **MVP 개발은 완료됐으며** 아래는 현재 제품 범위다.

## 기능

| 영역 | 현재 제공 |
| --- | --- |
| 인증 | Google 로그인, 첫 로그인 이름 확인, 세션 유지, 로그아웃, 미연결 안내 |
| 거래 | 생성·수정·삭제, 선택 소분류, 지출 결제 수단, 날짜·구성원/공용 귀속·메모 입력 |
| 내역 | 월 목록, 전체/수입/지출 필터, 기록 상세에서 수정·삭제 |
| 홈 | 월 이동, 수입·지출·잔액, 예산 상태, 날짜별 수입/지출 달력과 일별 내역 |
| 예산 | 월별 총예산·카테고리 배분 설정·수정·초기화, 지난달 예산 불러오기, 예산 페이지(사용·남은 금액, 카테고리별 예산과 지출) |
| 통계 | 선택 월 지출·수입의 카테고리별·구성원별 원그래프, 지출 결제 수단별 원그래프, 항목별 기록 보기 |
| 설정 | 내 이름 변경, 기본 결제 수단, 구성원 조회, 계정 없는 구성원 추가·이름 변경·숨김·복원, 카테고리 관리 |

## 데이터 규칙

- 같은 Household의 로그인 구성원은 모든 거래를 조회·생성·수정·삭제할 수 있다. 수입·지출은 같은 가계부 구성원 또는 공용에 귀속하며 기본값은 현재 사용자다. 귀속은 실제 입력자를 뜻하지 않는다.
- 로그인 사용자는 가계부 연결 전이라도 이름을 한 번 확인해야 앱을 사용한다. Google 이름은 후보일 뿐이며 확인 후에는 로그인 때 덮어쓰지 않는다. 이름은 앞뒤 공백 제거 후 1~30자다. 이름을 바꾸면 내 계정에 연결된 구성원 이름도 함께 바뀌고, 나중에 가계부에 연결될 때도 확인한 이름을 쓴다.
- 계정 없는 구성원은 로그인 권한이 없다. 이름은 앞뒤 공백을 제거하고 빈 이름을 거부한다. 숨김은 기존 기록을 보존하며, 숨긴 구성원은 새 귀속으로 선택할 수 없다. 기존 기록 수정 시 해당 구성원은 유지할 수 있다.
- 지출은 체크카드·신용카드·현금 중 하나 또는 미지정으로 기록한다. 수입에는 결제 수단이 없다. 기존 기록은 미지정으로 둔다. 개별 카드·청구일·할부는 다루지 않으며 신용카드도 거래 날짜에 한 번만 합산한다.
- 기본 결제 수단은 사용자별 설정이며 최초값은 체크카드다. 새 지출에 미리 선택되고 선택지 맨 앞에 표시된다. 나머지는 체크카드·신용카드·현금 순이다.
- 거래 금액은 1~2,147,483,647원 정수다. 숫자 또는 올바른 천 단위 쉼표 입력을 허용한다. 부호·소수·잘못된 쉼표는 거부하며 원문을 임의로 바꾸지 않는다.
- 월 예산은 0~2,147,483,647원 정수다. 입력은 숫자만 허용하며 미설정과 0원은 다르다.
- 예산은 달마다 독립이다. 이어받기·이월은 없고 과거·미래 달도 설정·수정하며 다른 달에 영향이 없다. 지난달 불러오기는 입력칸만 채우고 저장해야 반영된다.
- 예산은 가계부 전체 지출(공용·구성원 구분 없음)에만 적용한다. 배분은 지출 대분류(미분류 제외)에 0원 이상으로 하며 합계는 총예산 이하, 차액은 미배분이다. 빈칸은 배분 없음이다. 소분류 지출은 대분류 배분에 포함한다. 배분된 카테고리를 삭제하면 그 배분만 미배분이 된다.
- 초기화는 그 달 총예산과 배분을 지워 미설정으로 되돌린다. 먼저 저장한 쪽이 우선이며, 불러온 뒤 다른 사람이 바꾼 예산의 저장·초기화는 거부하고 다시 불러오게 한다.
- 통계는 선택 월 전체 기록을 내역 필터와 무관하게 집계한다. 카테고리는 대분류 기준(소분류 포함, 미분류 별도), 구성원은 구성원별(숨긴·계정 없는 구성원 포함)과 공용, 결제 수단은 미지정을 별도 항목으로 둔다. 각 차트 합계는 그 달 지출 또는 수입 총액과 같다.
- 거래 날짜는 서울 기준 달력 날짜다. 홈·내역·통계는 같은 선택 월을 쓰며 첫 진입과 서울 월이 바뀔 때 이번 달로 돌아간다. 내역 유형 필터는 목록에만 적용한다.
- 카테고리는 가계부별로 소유한다. 초기 추천 카테고리도 추가한 카테고리와 동일하게 이름 변경·삭제할 수 있으며 숨김은 제공하지 않는다. 소속 가계부와 수입/지출 유형은 생성 후 변경하지 않는다.
- 카테고리는 대분류 → 소분류 2단계까지다. 소분류는 같은 가계부·같은 유형의 대분류 아래에만 만들고 부모는 바꾸지 않는다. 거래는 대분류를 필수로, 소분류를 선택으로 기록하며 합계·예산은 대분류 기준이다. 같은 이름의 카테고리를 허용한다.
- 가계부마다 수입·지출 미분류를 하나씩 유지한다. 미분류는 이름 변경·삭제·소분류 추가를 할 수 없고 사용자가 기록에 선택할 수 없다. 이미 미분류인 기록은 수정 시 미분류를 유지할 수 있다.
- 대분류를 삭제하면 소분류도 함께 삭제하고 기존 거래를 같은 유형의 미분류로 옮긴다. 소분류만 삭제하면 거래는 대분류에 남는다. 거래 자체와 월 전체 합계는 보존된다.
- 삭제 확인은 “{이름}을 삭제할까요?”와 처리 결과(미분류 이동, 소분류 함께 삭제, 대분류에 유지)를 안내하며 거래 건수는 조회하지 않는다.
- 미연결 사용자는 가계부에 진입하지 못한다. 다른 Household 데이터는 RLS로 차단한다.

## 현재 미제공

가족 초대, 구성원 간 정산, 비공개 개인 기록, 여러 Household 전환, 예산 이어받기·구성원별 예산, 여러 달 추이·전월 비교·막대 차트, 반복 거래, 금융기관 연동, 알림, 실시간·오프라인 동기화는 제공하지 않는다. 초기 Household 연결은 관리용 SQL로 처리한다.

새 기능은 실제 사용 필요를 확인한 뒤 추가한다. 상세 완료 결과는 [MVP 완료 요약](MVP.md)에 있다.
