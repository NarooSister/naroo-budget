# 제품

Naroo는 부부가 같은 Household의 수입·지출을 빠르게 기록하는 가계부다. **MVP 개발은 완료됐으며** 아래는 현재 제품 범위다.

## 기능

| 영역 | 현재 제공 |
| --- | --- |
| 인증 | Google 로그인, 세션 유지, 로그아웃, 미연결 안내 |
| 거래 | 생성·수정·삭제, 날짜·구성원·메모 입력 |
| 내역 | 월 이동, 전체/수입/지출 필터, 거래 편집 |
| 홈 | 현재 월 수입·지출·잔액, 예산 상태, 최근 5건 |
| 예산 | Household의 월 전체 지출 예산 설정·수정 |
| 설정 | 구성원 조회, 카테고리 추가·수정·숨김·복원 |

## 데이터 규칙

- 같은 Household 구성원은 모든 거래를 조회·생성·수정·삭제할 수 있다. 거래의 기본 구성원은 현재 사용자이며 같은 Household 구성원으로 변경할 수 있다.
- 거래 금액은 1~2,147,483,647원 정수다. 숫자 또는 올바른 천 단위 쉼표 입력을 허용한다. 부호·소수·잘못된 쉼표는 거부하며 원문을 임의로 바꾸지 않는다.
- 월 예산은 0~2,147,483,647원 정수다. 입력은 숫자만 허용하며 미설정과 0원은 다르다.
- 거래 날짜는 서울 기준 달력 날짜다. 내역의 선택 월과 홈의 현재 월은 독립적이다.
- 카테고리는 Household와 수입/지출 유형에 속한다. 기본 카테고리는 이름을 수정할 수 없고 숨길 수 있다.
- 숨긴 카테고리는 새 거래에서 선택할 수 없다. 기존 거래를 수정할 때 그 거래의 숨긴 카테고리는 유지할 수 있다.
- 미연결 사용자는 가계부에 진입하지 못한다. 다른 Household 데이터는 RLS로 차단한다.

## 현재 범위 밖

가족 초대, 여러 Household 전환, 카테고리별 예산, 통계, 반복 거래, 금융기관 연동, 알림, 실시간·오프라인 동기화는 제공하지 않는다. 초기 Household 연결은 관리용 SQL로 처리한다.

새 기능은 실제 사용 필요를 확인한 뒤 추가한다. 상세 완료 결과는 [MVP 완료 요약](MVP.md)에 있다.
