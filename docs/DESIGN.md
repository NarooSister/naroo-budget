# 디자인

**MVP 화면 구현은 완료됐다.** 이후 UI 변경에서도 빠른 모바일 입력과 현재 스타일을 유지한다.

## 화면 흐름

- 이름 확인 전 로그인 사용자는 ‘이름 설정’ 화면에서 Google 이름(이메일이면 빈칸)을 확인하고 ‘시작하기’로 진입한다. 설정 상단의 수정 버튼으로 이름을 바꾼다.
- 기본 탭: 홈·내역·통계·설정. 기록 추가는 주요 액션 버튼으로 제공한다.
- 기록 추가: 금액 → 카테고리 → 저장. 기본값은 지출·오늘·현재 구성원이며 날짜·구성원·메모는 필요할 때 변경한다. 소분류가 있는 대분류를 고르면 아래에 ‘소분류 (선택)’을 표시하고, 다시 누르면 해제한다. 대분류·유형을 바꾸면 소분류 선택을 해제한다.
- 지출은 카테고리 아래 ‘결제 수단’ 세그먼트에 기본 결제 수단이 선택된 채 맨 앞에 표시된다. 선택한 항목을 다시 누르면 미지정이 된다. 수입으로 바꾸면 결제 수단을 숨기고 비운다. 설정에는 기본 결제 수단 세그먼트를 체크카드·신용카드·현금 순으로 둔다.
- 기록 항목은 ‘식비 · 장보기’처럼 분류를 제목으로, 메모를 그 아래 보조 줄에 표시한다. 내역 보조 줄에는 결제 수단도 붙인다.
- 홈: 월 이동과 오른쪽 지출·수입·잔액 → 예산(총예산 사용/예산·남음 또는 빨간 초과·진행 막대) → 일요일 시작 달력. 예산 영역은 예산이 있으면 예산 페이지, 없으면 설정 시트를 연다. 날짜 칸에 수입 +·지출 −를 작은 등폭 전체 숫자로 따로 표시하고 좁으면 글자를 줄인다. 접근성 레이블은 정확한 원 금액을 읽는다. 빠른 추가 버튼은 항상 오늘로 연다.
- 예산 시트: 예산 없는 달은 ‘지난달 예산 불러오기’ → 총예산 → (총예산 입력 후) 지출 대분류별 배분 칸(빈칸은 회색 0, 배분 없음)과 실시간 미배분/초과 → 저장 → 기존 예산이면 아래 빨간 ‘예산 초기화’(취소 강조 확인). 배분 합계 초과는 저장을 막고 안내한다. 충돌 시 안내와 ‘다시 불러오기’를 표시하고 저장을 막는다.
- 예산 페이지: 하단 탭 유지, 홈과 같은 월 이동, 우측 상단 수정. 총예산 진행 → 카테고리별 예산(배분된 카테고리만, 미배분 금액 표시). 항목을 누르면 그 달 해당 카테고리(소분류 포함) 지출 시트, 기록은 상세 시트로 연다.
- 날짜를 누르면 그날 합계·내역 시트를 띄우고 ‘이 날짜에 기록 추가’를 제공한다. 지정 날짜로 열면 입력 화면에서 날짜 옵션을 펼쳐 보여 준다.
- 내역: 월 이동과 유형 필터, 날짜별 목록.
- 통계: 홈·내역과 같은 월 이동 → 지출/수입 세그먼트 → 섹션별 도넛(가운데 유형·월 총액)과 금액 순 범례(색 점·이름·정수 %·금액). 지출은 카테고리별·구성원별·결제 수단별, 수입은 카테고리별·구성원별. 모든 항목을 조각으로 표시하고 기타로 묶지 않는다. 색은 금액 순으로 `NarooColors.chart`를 배정한다. 조각이나 범례 행을 누르면 조각을 강조하고 그 달 해당 기록 시트를 연다. 빈 유형은 ‘이 달 지출(수입)이 없어요.’를 표시한다.
- 일별 시트와 내역의 항목은 같은 기록 상세 시트(금액·날짜·구성원·결제 수단·메모)로 연다. 상세에서 ‘수정’은 기존 입력 화면, ‘삭제’는 확인 후 삭제하고 이전 시트로 돌아간다.
- 카테고리 관리는 설정에서 한다. 기록 입력 중 카테고리를 생성하지 않는다.
- 카테고리 관리는 추가·수정·삭제를 제공한다. 초기 추천 분류도 편집하며 숨김 UI는 없다. 소분류는 대분류 아래 들여 써서 표시하고 대분류의 ‘소분류 추가’ 버튼으로 만든다. 미분류에는 버튼을 표시하지 않는다. 삭제 확인 제목은 ‘{이름}’을 삭제할까요?이고 본문은 미분류 이동 / 소분류도 함께 삭제 / ‘{대분류}’에 남음 중 해당 결과를 표시하며 건수는 넣지 않는다.
- 구성원 추가·이름 변경·숨김/복원은 설정에서 한다. 기록의 구성원 선택에는 공용을 함께 표시하고, 기존 기록의 숨긴 구성원은 숨김 상태를 표시한다.
- 저장 확인 팝업은 추가하지 않는다. 삭제는 확인하며 취소를 더 눈에 띄게 표시한다.

## 상태 처리

- 조회 중에는 필요한 영역만 로딩 표시하고 재조회 중 기존 데이터를 가능한 한 유지한다.
- 저장 중에는 버튼 안의 스피너를 표시하고 중복 요청을 막는다.
- 빈 화면에는 짧은 설명과 다음 행동을 제공한다.
- 실패 시 이해 가능한 문구와 재시도를 제공한다. 내부 오류·stack trace를 노출하지 않는다.
- 입력 실패와 저장 실패 후 입력 원문을 유지한다.

## 스타일

테마의 기준은 `lib/app/theme/`다. 새 화면은 기존 토큰과 위젯을 재사용한다.

- 아이보리 배경, 흰 표면, 저채도 세이지 주요 액션. 수입/지출은 색과 +/-를 함께 사용한다.
- Pretendard를 사용하고 금액은 등폭 숫자로 표시한다. 금액 32 Bold, 제목 22 Bold, 섹션 17 SemiBold, 본문 15 Medium, 보조 14 Regular, 캡션 12 Regular.
- 간격은 4의 배수, 좌우 여백 20, 주요 버튼 높이 52, 터치 영역 최소 48.
- 모서리: 버튼 16, 입력 14, 카드·다이얼로그 20, 시트 상단 24.
- Lucide 라인 아이콘을 사용한다. 카테고리 선택은 4열이다.
- 카드 중첩·강한 그림자·그라데이션·장식 애니메이션은 피한다. 통계 도넛의 짧은 그려지는 전환만 허용한다.

iPhone·Android 브라우저/PWA의 좁은 화면과 한 손 사용을 우선한다. UI 변경은 입력 속도·가독성·터치 수를 기준으로 판단한다.
