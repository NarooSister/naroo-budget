# 결제 수단

## 목표·범위

지출에 체크카드·신용카드·현금을 기록한다. 사용자 이름 설정은 완료했고 결정은 PRODUCT.md·DESIGN.md·ARCHITECTURE.md에 반영했다.

## 주요 결정

- 확정: 지출만 결제 수단을 가진다. 수입에는 적용하지 않는다.
- 확정: 새 지출의 기본 결제 수단은 설정에서 고르며 최초 기본값은 체크카드다. 미지정도 허용한다. 기존 기록은 미지정으로 보존하며 방법을 추정하지 않는다.
- nullable 필드 + 허용 세 값 CHECK를 사용한다. 수입 거래는 결제 수단이 없어야 한다.
- 기본값의 저장 위치(가계부 공통/사용자별)는 구현 전에 확정한다.
- 개별 카드·청구일·할부·계좌 잔액은 포함하지 않는다. 신용카드도 occurred_on 기준으로 지출을 한 번만 합산한다.

## 검증 기준

- 세 결제 수단의 생성·수정·표시, 기본값 변경·적용, 기존 미지정 호환, 수입 결제 수단 차단, 유형 변경 시 정리, 금액 합계 회귀.
- 완료 시 PRODUCT.md·DESIGN.md·ARCHITECTURE.md를 갱신하고 이 계획을 삭제한다.
