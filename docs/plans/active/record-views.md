# 내역의 달력·목록·상세

## 목표·범위

월 이동·지출/수입 → 예산 설정 → 목록/달력 전환 → 해당 보기를 배치한다. 달력 날짜 선택 → 그날 내역 → 기록 상세 흐름을 제공한다.

## 주요 결정

- 상태 설계 우선안: 기존 내역 탭을 이 화면으로 확장하고 별도 기록 화면을 만들지 않는다. 내역의 선택 월·보기·날짜를 하나의 상태로 유지한다. 앱 첫 진입 위치와 기본 보기는 여전히 미결정이며 화면 구현 전에 확정한다.
- 상단 합계·예산은 선택 월 전체 기준이다. 목록 유형 필터는 목록에만 적용하고 달력/상단 합계를 바꾸지 않는 안을 권장한다. 전환·상세 복귀 시 월/선택일/필터를 유지한다.
- 달력은 전환 버튼 바로 아래, 선택일 합계·내역은 달력 아래에 둔다. 날짜 셀의 수입+/지출−는 따로 합산한다. 최초 달력 선택은 오늘, 다른 월 이동 시 1일을 권장한다.
- 셀 축약 우선안: 절댓값 1,000원 미만은 원, 1만원 미만은 천원, 그 이상은 만원 단위로 내림·소수 첫째 자리까지 표시하고 불필요한 .0은 생략한다. 예: −950원 / −1.2천 / −123.4만. 셀 근처에 단위·축약 안내를 두고 선택일 합계/상세/접근성 레이블에는 정확한 원 금액을 제공한다.
- 내역·달력 아래 기록·홈 최근 5건 모두 같은 상세로 진입한다. 상세에서 수정/삭제하며 복귀 상태를 유지한다. 수정은 현재보다 한 번 더 누르는 흐름임을 UI 검토한다.
- 달력에서 추가하면 선택 날짜를 초깃값으로 명확히 표시한다. 월 데이터는 한 번 조회해 날짜별로 계산하며 날짜 클릭마다 재조회하지 않는다. 저장 성공 시 관련 합계·목록·상세를 갱신한다.

## 검증 기준

- 참고 이미지 순서·기준 월 일치, 보기/필터 전환·상세 복귀, 날짜 선택·추가·수정·삭제·빈 날, 서울 날짜/월·연도 경계.
- 360px·7열·6주 달·큰 합계·글자 확대·축약 경계/내림·접근성 정확한 금액.
- 완료 시 DESIGN.md의 기존 직접 편집 흐름을 상세 흐름으로 교체하고 PRODUCT.md·ARCHITECTURE.md의 상태/갱신 규칙을 반영한다.
