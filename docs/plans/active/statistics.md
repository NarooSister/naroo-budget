# 월 요약·통계

## 목표·범위

과거 월의 예산·지출을 확인하고 사용자/임의 구성원/공용·분류·결제 수단별 통계를 제공한다. 통계 추가는 확정이며 지표·화면·순서는 후속 결정한다.

## 주요 결정

- 선행 조건: 귀속·소분류·결제 수단 의미와 월 예산 승계 규칙 확정. 데이터가 안정된 뒤 구체 지표를 정한다.
- 월 요약은 선택 월 전체 수입·지출·잔액·예산·남은/초과 금액을 사용한다. 내역의 목록 필터와 구분한다.
- 후보: 구성원/공용 비용, 카테고리·소분류 비중, 예산 대비 사용, 결제 수단별 금액, 전월 비교·월 추이.
- 미설정·0원 예산·배분 없는 분류·결제 수단 미지정 데이터를 별도로 처리한다. 귀속/부모/자식 합계는 중복 계산하지 않는다.
- 과거 거래 수정 시 해당 월 사용액은 재계산한다. 여러 달 조회량이 커질 때 서버 집계를 검토한다.
- 분류/구성원은 이름 대신 ID로 집계한다. 이름 변경은 과거 표시에도 반영하고 카테고리 삭제 시 과거 분류 금액은 같은 유형의 미분류로 이동한다. 이동 전후 월 전체 합계는 같아야 한다.

## 검증 기준

- 빈 월·과거 월·0원 예산·초과·기존 미지정 데이터, 목록 필터와 전체 집계 분리, 그룹 합계 일치, 다른 가계부 차단.
- 완료 시 PRODUCT.md의 현재 미제공 통계를 제공 기능으로 갱신하고 DESIGN.md에 확정 화면을 반영한 뒤 이 계획을 삭제한다.
