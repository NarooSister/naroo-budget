# 월 예산 승계·카테고리 배분

## 목표·범위

전체/카테고리별 예산을 다음 달에도 적용하고 과거 월 설정을 보존한다. 8월 300 → 9월 350 변경이면 8월은 300, 10월은 350이다. 남은 금액을 더하는 이월은 포함하지 않는다.

## 주요 결정·진입 조건

- 우선안: 전체 예산과 카테고리 배분을 한 묶음의 완전한 설정으로 저장한다. 카테고리별 개별 승계는 사용하지 않는다. 배분 해제는 새 묶음에서 해당 항목을 빼는 것으로 표현하고 저장은 원자적으로 처리한다.
- 확정: 총예산을 먼저 설정하고 일부 배분을 허용한다. 배분은 0 이상의 정수이며 합계는 총예산 이하, 차액은 미배분으로 표시한다. 미설정 복귀 허용, 미래 월 선설정 정책과 승계 시작 월·기준값은 migration 전에 정한다. 대분류 배분을 우선하고 소분류 지출은 부모 지출에 포함한다.
- 사용자가 설정한 월과 과거 수정 보존용 경계 월에만 저장한다. 시작 월 이후 조회는 해당 월 이하에서 가장 최근 유효 묶음을 사용한다. 조회·미래 탐색·미접속 복귀는 DB 행을 생성하지 않는다.
- 과거 월 M을 수정할 때 M+1에 설정이 없으면 수정 전 M+1의 유효 묶음을 먼저 고정하고 M을 변경한다. 이미 있는 M+1은 보존한다. 보존할 값은 M의 값이 아니라 M+1의 기존 조회 결과이며, 미설정 상태도 별도 명시값으로 보존한다.
- 이번 달 변경은 다음 달부터 이어 적용한다. 별도 미래 설정이 있으면 그 월부터는 해당 설정이 우선한다. 경계 생성+변경은 가계부별 직렬화/잠금과 트랜잭션으로 처리한다. 우회 직접 쓰기는 제한하고 동일 저장 경로로 이력 규칙을 보장한다.
- 가계부별 승계 시작 월을 명시하고 기준 묶음을 만든다. 시작 전에는 기존 해당 월 행만 조회하며 빈 월은 미설정으로 유지한다. 초기 기준값 선택을 확인하고 기존 명시 월 행을 덮어쓰지 않는다.
- 기존 데이터는 전체 금액과 빈 배분으로 보존한다. 묶음에는 0원과 미설정을 구분하는 상태가 필요하다. 삭제/배분 해제도 과거 보존 경로로만 처리한다.
- 대안인 조회 시 누락 월 생성은 월별 실체 행을 요구할 때만 재검토한다. 현 우선안은 읽기 부작용과 대량 보충이 없어 단순하지만 과거 수정·동시 저장·기준 월 검증은 여전히 필요하다.

## 검증 기준

- 8→9→10 승계, 과거 M 수정 후 M+1·이후 달 보존, 기존 M+1·미래 설정 우선, 시작 월 직전 수정, 연도 경계.
- 출시 전 빈 달 보존, 시작 월 기준값, 여러 달 미접속·미래 조회 후 행 수 불변, 미설정 경계/0원/최댓값.
- 전체+배분 원자성·배분 해제·일부 배분/미배분·합계 초과 거부·부모 집계·다른 가계부 차단·동시 저장/재시도. 저장 경로 우회 차단도 실제 DB에서 검증한다.
