# 기능 확장 개요

## 목표·확정 범위

빠른 입력을 유지하며 구성원/공용 귀속·소분류·결제 수단을 저장하고 달력/목록/상세, 월 예산·배분, 통계를 확장한다. 제목 입력은 추가하지 않고 카테고리·소분류 아래에 메모를 표시한다. 구성원·귀속, 소분류, 사용자 이름, 결제 수단, 홈 달력·기록 상세, 월 예산·배분은 완료했고 결정은 PRODUCT.md·DESIGN.md·ARCHITECTURE.md에 반영했다. 통계만 계획 단계다.

- 결제 수단 통계 지표는 추후 결정한다.

## 남은 순서

1. [통계](statistics.md): 지표·화면 결정. 그 밖의 계정 삭제·이름 제약·정렬·성능 검토는 [DB 후속 결정](database-followups.md)에 둔다.

## 검증·문서 정리

각 코드 변경 후 flutter analyze와 flutter test를 실행한다. 금액·날짜·월 합계·예산·가계부 접근 회귀를 확인하고, Fake/HTTP와 실제 OAuth·DB/RLS·브라우저 검증을 구분한다.

기능 완료 시 해당 계획의 결정을 PRODUCT.md·DESIGN.md·ARCHITECTURE.md에 반영하고 그 계획을 삭제한다. 개요에는 남은 범위만 유지한다.
